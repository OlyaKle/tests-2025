### Выбор проекта
Для анализа и тестирования был написан простой проект "калькулятор", в котором реализованы функции сложения, вычитания, умножения, деления двух чисел и возведение в степень.

Проект имеет структуру:
- calculator.py, где описан класс выполнения операций
- validation.py, где прописан процесс инициализации получаемых данных
- app.py - само приложение с прописанной html формой и запуском необходимых функций
- tests.py - интеграционные тесты

### Анализ
Ключевые точки интеграции в проекте калькулятора:
- Веб-интерфейс → API - разные шаги для формы и JSON API, через которые входят запросы и выходят ответы;
- API → Валидация - проверка входных данных перед вычислениями;
- Валидация → Калькулятор - передача проверенных данных в математический модуль;
- Калькулятор → Обработка ошибок → Пользователь - полный путь ошибки от места возникновения до конечного пользователя;
- Форма HTML → Бэкенд обработка - интеграция веб-интерфейса.

Критическим участком является функция деления двух чисел. Важно проверить не является ли делитель нулём. 

### Написание тестов
#### тест 1 - проверка успешности вычислений через API
`test_calculation_flow_success` - проверяет базовую интеграцию: API → валидация → калькулятор → ответ
<img src="https://github.com/OlyaKle/tests-2025/blob/main/запуск-тестов.jpg" width="500" alt="тест1">

#### тест 2 - проверка интеграции всех мат операций
`test_all_operations_integration` - тестирует взаимодействие всех модулей для разных операций, проверяет согласованность системы

#### тест 3 - проверка потока обработки ошибки деления на ноль
`test_division_by_zero_error_flow` - критически важный тест, проверяющий как ошибка из модуля калькулятора проходит через все слои и корректно обрабатывается

#### тест 4 - проверка интеграции модуля валидации с API
`test_validation_integration` - проверяет интеграцию модуля валидации с API, что особенно важно для безопасности

#### тест 5 - проверка обработки недопустимой операции
`test_invalid_operation_flow` - тестирует обработку некорректных входных данных на уровне всей системы
