Также важными деталями проекта являются декораторы(из app.py):
1. `@app.route('/calculate', methods=['POST'])` связывает URL-адрес с функцией-обработчиком.

Что он делает:

когда пользователь заходит на корневой URL (http://localhost:5000/), Flask вызывает функцию index(). Функция возвращает HTML-форму калькулятора.

<img src="https://github.com/OlyaKle/tests-2025/blob/lab2/декоратор1.jpg" align="center" width="350" alt="декоратор1">

2. `@app.route('/')` обрабатывает данные, отправленные из html формы.

Что он делает:

'/calculate' - URL, на который отправляется форма, а `methods=['POST']` - указывает, что этот маршрут принимает только POST-запросы. Так функция получает данные из HTML-формы через request.form.

POST используется для отправки данных, которые изменяют состояние сервера, при этом данные формы передаются в теле запроса, а не в URL, что более безопасно для передачи чувствительных данных.

<img src="https://github.com/OlyaKle/tests-2025/blob/lab2/декоратор2.jpg" align="center" width="350" alt="декоратор2">

3. `@app.route('/api/calculate', methods=['POST'])` предоставляет API для программного доступа

Что он делает:

Аналогично предыдущему, но работает с JSON данными. То есть декоратор использует request.get_json() вместо request.form, возвращает JSON ответ вместо HTML.

Зачем нужны два похожих маршрута:
- /calculate - для веб-браузеров (HTML форма)
- /api/calculate - для мобильных приложений, других сервисов (JSON API)

### Анализ
Ключевые точки интеграции в проекте калькулятора:
- Веб-интерфейс → API - разные шаги для формы и JSON API, через которые входят запросы и выходят ответы;
- API → Валидация - проверка входных данных перед вычислениями;
- Валидация → Калькулятор - передача проверенных данных в математический модуль;
- Калькулятор → Обработка ошибок → Пользователь - полный путь ошибки от места возникновения до конечного пользователя;
- Форма HTML → Бэкенд обработка - интеграция веб-интерфейса.

Критическим участком является функция деления двух чисел. Важно проверить не является ли делитель нулём.
